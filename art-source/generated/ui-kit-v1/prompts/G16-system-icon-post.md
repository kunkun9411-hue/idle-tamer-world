# G16 – Post / Mail

Single HD Silver-Ether system icon for Idle Tamer World: a polished silver
sci-fi communication post with a compact envelope, a violet Ether-crystal
seal, restrained metallic bevels, and a readable silhouette at 64 px. Front
facing, centered, square composition, no text, letters, numbers, watermark,
UI frame, or extra objects. Premium contemporary game UI asset, clean
cel-shaded 3D illustration, not pixel art.

Backdrop: perfectly uniform chroma green `#00ff00` covering the full canvas;
the icon itself contains no green. Keep the chroma source unchanged under
`../chroma/system-icon-g16-v1-chroma.png`; the alpha master is generated at
`../transparent/system-icon-g16-silver-ether-v1-master.png`.
