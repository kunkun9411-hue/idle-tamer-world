# G21 – Information

Single HD Silver-Ether system icon for Idle Tamer World: a polished silver
sci-fi information beacon with a centered circular frame, violet Ether crystal
orb, and a small abstract luminous information glyph built only from geometric
shapes. Front-facing, centered, readable at 64 px, no letters, words, numbers,
watermark, UI frame, or extra objects. Premium contemporary game UI asset,
clean cel-shaded 3D illustration, not pixel art.

Backdrop: perfectly uniform chroma green `#00ff00` covering the full canvas;
the icon itself contains no green. Keep the chroma source unchanged under
`../chroma/system-icon-g21-v1-chroma.png`; the alpha master is generated at
`../transparent/system-icon-g21-silver-ether-v1-master.png`.
