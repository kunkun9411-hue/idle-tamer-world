# G23 – Erfolg / Haken

Single HD Silver-Ether system icon for Idle Tamer World: a polished silver
sci-fi confirmation beacon with a compact circular shield silhouette, luminous
mint-green Ether core, and an abstract geometric checkmark symbol. Front-facing,
centered, readable at 64 px, no words, letters, numbers, watermark, UI frame,
or extra objects. Premium contemporary game UI asset, clean cel-shaded 3D
illustration, not pixel art.

Backdrop: perfectly uniform chroma green `#00ff00` covering the full canvas;
the icon itself contains no green. Keep the chroma source unchanged under
`../chroma/system-icon-g23-v1-chroma.png`; the alpha master is generated at
`../transparent/system-icon-g23-silver-ether-v1-master.png`.
